# WAAMLABZ Logger releases

Each release contains a signed, compiled update package named `waamlabz-<version>.tar.zst`, built from the private source repository. Apart from this README, only these release packages are published here: no source code, keys, or other files.

## Install an update

1. Download the package from [Releases](https://github.com/DraxABGit/waamlabz-releases/releases).
2. Copy it to a USB drive and insert the drive into the rig.
3. In the app, open **SETTINGS > UPDATE > Import Update...** and select the package.

The app verifies the signature and license automatically. A package can only be installed on a rig with a valid license and only if its version is newer than the installed version.

Published packages are never replaced. Every new version is published as a new release.
